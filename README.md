# Loan Approval Prediction

## Project Overview

A **machine learning classification project** for predicting loan approval using historical financial and applicant data.

## Business Goal

To support **faster, consistent, and data-driven loan decisions** while reducing the cost of incorrect approvals and denials.

## Methodology

The project follows the **CRISP-DM framework**:

* Business Understanding
* Data Understanding
* Data Preparation
* Modeling
* Evaluation
* Deployment

## Models

* Logistic Regression
* Decision Tree
* Random Forest

Models are compared using **cross-validation**, **precision**, **recall**, **F1-score**, and **ROC-AUC**.

## Key Tools

**Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook**
